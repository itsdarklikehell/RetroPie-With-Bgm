# RetroPie-With-Bgm

RetroPie setup met achtergrondmuziek.

## Installatie

```bash
git clone https://github.com/itsdarklikehell/RetroPie-With-Bgm.git
cd RetroPie-With-Bgm
./install.sh
```

## Gebruik

Start RetroPie op en de achtergrondmuziek start automatisch.
